# Bibliotèque
## HTML
1. Petit projet d'un bibliotèque en HTML
2. Créer un projet github nommé bibliotheque-html avec un readme contenant la description du projet.
3. Cloner le projet en local.
4. Créer une branche dev en local.
5. Sur la nouvelle branche, créer un fichier index.html.
6. Faire des commits réguliers en fonction des différentes parties à créer.
7. Dans le fichier index, créer une bibliothèque avec 6 couvertures de livres, rangées en lignes et colonnes avec un header contenant le titre du projet. Chaque couverture doit avoir une légende avec le titre du livre.
8. Le clic sur la couverture doit envoyer vers la page du livre, avec à gauche l’image de la couverture, au milieu le titre et un résumé du livre ; et à droite un lien de téléchargement du livre et un autre vers la page index.
9. Faire en sorte que le contenu des pages prenne la largeur de l’écran.
10. Utiliser le plus possible les balises sémantiques.
11. Rajouter le header et le footer dans toutes les pages. Le footer doit avoir une colonne avec quelques liens vers les réseaux sociaux et une autre avec un formulaire de contact, contenant nom, email, message et bouton d’envoi avec des icones provenant de fontawesome.
12. Faire la fusion sur la branche main et supprimer la branche dev.
13. Envoyer le tout sur github.
